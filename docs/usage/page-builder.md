# Page Builder regions

Nexus Sports gives you **40 regions**: places on the storefront where you can drop
Page Builder widgets (text, images, banners, buttons, HTML) without editing code.

1. Go to **Storefront › Themes › Edit in Page Builder**.
2. Pick the page from the **Page** menu at the top left.
3. Drag a widget from the left panel onto a dashed *Drag and drop widgets here* box.
4. **Publish**.

An empty region takes no space on the live store, so you can leave any of them
empty.

!!! info "Global regions"
    Regions whose name ends in `--global` sit in the header, footer or cart
    drawer. A widget placed in one shows **on every page at once**: build your
    footer once, not once per page type.

## Every page (global)

| Region | Where |
|---|---|
| `header_mega_feature--global` | Promo tile inside the mega menu |
| `header_quick_search_popular--global` | "Popular searches" tags in the search panel |
| `cart_drawer_shipping--global` | Shipping note inside the cart drawer |
| `footer_brand--global` | Short text under the footer logo |
| `footer_column_1--global` | First footer link column |
| `footer_column_2--global` | Second footer link column |
| `footer_column_3--global` | Third footer link column |
| `footer_bottom--global` | Strip at the very bottom |

| `home_below_brands` | After the brand strip |
